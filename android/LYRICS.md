# 内置歌词搜索、标注与标签固化

版本：0.5.0 / versionCode 6。日期：2026-10-29。

## 使用

1. 在歌曲菜单选择「联网搜索／标注／固化歌词」，或在歌词页选择「搜索与固化歌词」。
2. 选择 QQ 音乐或网易云音乐，调整默认的曲名、歌手搜索词，点击「联网搜索」。候选显示平台曲名、歌手、专辑和时长差。
3. 点击候选预览。可以编辑歌词曲名、歌手、专辑、整曲偏差和版本／试听备注。整曲偏差单位为毫秒，正数延后，范围 ±30000；按钮每次调整 200ms。
4. 「采用歌词并保存逐曲标注」只保存应用内的离线歌词。播放当前歌曲时可查看同步预览、点击时间行定位试听；未播放的歌曲不跳转其他歌曲的进度。
5. 确认原文、译文和录音版本后，点击「一键固化双语歌词到歌曲标签」。未保存的标注会先保存，然后固化这一版标注。固化暂停播放，并保留本次操作前的完整歌曲副本。
6. 可在同一面板恢复固化前的完整歌曲；「我的 → 设置 → 歌词固化恢复记录」可查找已有恢复记录，歌曲因失败而从扫描结果消失后仍可恢复。

曲名／歌手／专辑编辑的是歌词的 LRC 头信息，不更改音频本身的 TITLE、ARTIST、ALBUM 标签，也不修改分类署名。搜索不上传本地音频；平台会收到搜索词及候选 ID，使用 HTTPS 直连平台。

## 可行性与实现取舍

原生 Android 端可以独立完成检索、选择、标注和写标签，不依赖电脑或 lrc-match 本机服务。复用了交接文档中「平台检索 → 候选 → 人工试听 → 明确采用」的产品流程；未移植 Python / Qt，也未将 LDDC GPL 源码复制进 APK。

搜索成功、结构有效与录音匹配是三个不同结论。本版由用户选中和试听，不进行全库自动匹配，不把平台排名或时长相近视为匹配证明。没有模型 API、ASR、音频指纹、强制对齐或自动翻译。译文只来自平台实际返回的同步译文。

| 模块 | 实现 |
|---|---|
| LyricsProviders | QQ / 网易云直接请求、候选元数据、原文和译文；连接／读取／总超时，单来源请求间隔与 429 退避 |
| LyricsDocument | 有界 LRC 解析、独立时间轴合并、标注检查、来源和偏移记录 |
| LyricsManager | 单工作线程、有界队列、候选 token、逐曲 revision、AtomicFile 离线选择、备份与恢复日志 |
| AudioTagEditor | jaudiotagger 3.0.1 修改暂存文件；歌词回读、其他标签和音频数据校验 |
| ContainerLyrics / TagReader | AIFF / WAV / M4A 内嵌歌词重扫回读；保留原有其他格式读取 |
| PlaybackService / MusicLibrary | 扫描与固化互斥，写入时释放播放源，恢复队列与位置并保持暂停 |
| native-tools.js | 搜索、候选预览、逐曲标注、采用、固化、恢复记录 |

## 标签与时间规则

- 使用标准歌词字段：FLAC 的 LYRICS、MP3/AIFF/WAV 的 ID3 歌词、M4A/MP4 的 ©lyr。内容是带毫秒时间戳的双语 LRC；不同播放器能否解析该字段内 LRC 取决于其自身实现。
- 原文和译文分别解析、按各自真实时间排序；同时间原文在先。只去掉完全相同的重复行，不用数组下标强行配对，也不凭空制造译文。
- 来源的 offset 与用户偏差各应用一次；最终偏差烘焙进时间戳，输出 offset:0，并另存 m3x_offset_ms 供追溯。负时间截到零。已采用歌词不再叠加全局偏移，防止重复偏移。
- 输出包含 ti/ar/al、平台和 song ID、应用标识、用户偏差和备注。原平台字段也保存在应用内选择文档中，便于区分来源信息与编辑标注。
- 已采用歌词优先于下载歌词、同名 LRC 和原内嵌歌词；离线采用文档损坏时提示并退回原读取链路。歌曲 URI、标题、原歌手、专辑、时长或 CUE 起点变化会使旧选择失效。

## 边界处理

| 情况 | 行为 |
|---|---|
| 离线、超时、服务限制、平台接口失效 | 提示失败，保留已采用的离线歌词；用户可换来源或重试 |
| 搜不到／版本不一致 | 修改搜索词、切换平台、试听后再采用，不自动覆盖 |
| 无同步原文 | 拒绝采用结构无效的候选 |
| 有原文、无同步译文 | 可预览、采用原文；禁止以「双语」名义固化 |
| 原译时间不同、行数不同 | 保留独立时间轴，不按行号配对；需用户试听确认 |
| 偏差超过 ±30 秒 | 明确拒绝；可能是错误录音或需要逐段对齐 |
| CUE 虚拟分轨／远程歌曲／未支持格式 | 可搜索和采用；禁止直接固化共享或远程文件 |
| 本地 FLAC、MP3、AIFF/AIF/AIFC、WAV、M4A/MP4 | 允许尝试暂存编辑；容器、其他标签或音频校验失败就拒绝提交 |
| 只读文件、SAF 写授权缺失 | 操作失败，原文件不提交或自动回滚；保留可恢复副本 |
| 空间不足 | 写入前预检应用空间，需约两份歌曲大小加 16MiB；同目录临时替换也需要源存储空间 |
| 大曲目／大型封面 | 后台流式复制和散列，避免整曲载入内存；操作时间和空间随文件大小增加 |
| 快速重复点击、关闭面板、旧候选 | 有界队列和 token/revision 检查，旧响应不切换已关闭面板；已提交的后台写入仍完成 |
| 扫描正在运行／播放源正在准备 | 阻止固化，稍后重试；固化期间不启动扫描或切换播放源 |
| 暂存写入后其他标签／封面变化 | 对非歌词字段原始内容取散列比对，失败时不提交；部分特殊文件会因此保守拒绝 |
| 其他应用同时改文件 | 提交前再次比较完整源文件 SHA；发现变化拒绝覆盖。检查与提交间仍有极短竞争窗口，不能承诺跨应用锁 |
| 写入后校验失败 | 尝试恢复完整原文件并校验；双重失败保留日志与完整恢复副本 |
| 进程被杀／SAF 部分写入 | 恢复记录显示未完成状态，明确勾选后允许完整副本覆盖未知的当前内容 |
| 固化完成后外部改文件 | 常规恢复拒绝覆盖，不允许用中断恢复选项绕过完成记录的保护 |
| 歌曲被删除／授权撤回／SD 卡拔出 | 保留日志和备份；需恢复相同路径或授权后重试，不能重建已删除的文档 URI |
| 多次固化 | 只保留最近一次完整撤销副本，第二次的恢复点是第一次固化后的文件 |
| 卸载应用／清空应用数据 | 私有标注、恢复日志与备份随之丢失；已固化到歌曲的歌词仍在文件中 |

## 提交与恢复

普通 file URI：完整复制原文件 → 暂存编辑 → 歌词／其他标签／音频校验 → fsync 备份与日志 → 同目录临时副本 → rename 替换 → 完整回读 SHA 校验。替换保留文件权限位；不是保留原修改时间。

SAF content URI：文档提供者不保证原子替换。完整私有副本与日志先落盘，再用 rwt 写入并 fsync、回读 SHA；失败则立即尝试回滚。断电时文件可能暂时不完整，必须通过恢复记录修复。恢复操作自身再次中断时，日志仍指向已验证的原始恢复副本。

应用内副本不是独立备份系统；保留一层撤销，不代替用户的曲库备份。未实测的特殊容器、未知自定义块和文件系统断电持久性不能由测试夹具推定。

## 验证记录

2026-10-29，Android 7.1.1 / API 25 x86_64 模拟器，全部使用合成音频：

- JVM 共 23 项通过，含新增 5 项 LRC/偏移/边界测试；Debug Lint 和签名 Release 构建通过。
- 11 个格式用例通过：FLAC，AIFF 8/16/24/32 位，AIFC，AAC M4A，ALAC 16/24 位，带封面与 ReplayGain 的 MP3，含 INFO 的 WAV。校验歌词 Unicode 回读、音频散列、其他标签、再次写入和扫描回读。
- 本地固化、连续固化、完整 SHA 撤销、外部修改拒绝；SAF 正常、只读、截断后注入失败的回滚通过。
- 中断后源文件被截断、歌曲从曲库消失、仅剩 AtomicFile 日志备份：未明确允许时拒绝，明确恢复后完整 SHA 与原文件一致。
- QQ / 网易云实际联网检索与同步译文获取通过。QQ 实际 UI 搜索 → 标注 +1200ms → 采用 → 写标签 → 音频散列不变 → 完整恢复通过。
- 扫描恢复与播放回归通过；完整后台播放回归通过，Release 19 项通过；最终恢复补丁的 4 项回归通过，详见 [verification-lyrics-0.5.0.json](verification-lyrics-0.5.0.json)。旧测试中依赖已移除 m3x-ripple 元素的断言改为导航点击，保留播放行为验证。
- 本次未操作 M3X 真机或用户音乐，未重测 lrc-match 的 14 首 AIFF，不将此前试听结果当作本版本的匹配正确率。

真实设备的 SD 卡／SAF 提供者、断电恢复、长曲与特殊标签仍需用备份副本验收。平台直接接口没有本项目的稳定性保证，可能变化或限制；产品分发前需另行确认平台使用条件及歌词授权范围。

## 开发与测试

入口测试：LyricsLogicTest、LyricsTagTest、NativePlayerTest 中 test050 三项、LyricsOnlineTest、LyricsOnlineUiTest。在线两类测试会访问外部平台，离线默认回归不应依赖它们成功。

新增 fixture-tags.mp3 与 fixture-tags.wav 为 FFmpeg 8.0.1 的 lavfi sine（440Hz、44100Hz、2秒）生成；MP3 使用 libmp3lame 128k，附 32×32 蓝色合成封面、测试署名和 ReplayGain -3dB；WAV 为 PCM16。无商业音乐或下载歌词入库。

为 API 25 的 java.nio.file 路径接口使用 desugar_jdk_libs_nio:2.1.4。jaudiotagger 未修改，固定 3.0.1，许可与源码地址见 licenses/Jaudiotagger-LGPL-2.1.txt，并随 APK 的许可证页面打包。可替换 Gradle 依赖后按 README 构建；本地分发目录同时提供该库源码及应用源代码包，签名私钥不包含在包中。
