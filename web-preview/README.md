# 澄 · Shiny Colors 本地网页预览

## 打开

在终端运行：

```powershell
python D:\CodeFile\M3X-Player\web-preview\server.py
```

浏览器打开 `http://127.0.0.1:18765/`。服务只监听本机；在运行服务的终端按 Ctrl+C 停止。

不需要 npm、构建步骤、登录或联网。页面打开不会自动播放，音量由系统控制；点击切歌会立即播放。

页面只展示播放器，不包含介绍侧栏、演示标签或开发说明。布局从「我的 → 软件设置」调整；手机宽度下界面铺满屏幕。正常播放不显示常驻提示，播放失败时保留错误反馈。

## 可测试

### 创建曲库与分类预览

曲库顶部「管理曲库分类」（未应用时为「创建曲库」）使用
`D:\BaiduNetdiskDownload\THE_IDOLMASTER` 的已保存分类快照，共 4,235 首。网页操作不直接修改已安装的 APK；0.3.0 构建时会将当前保存配置编入原生扫描分类。

- 直接打开已确认的角色、组合、歌手和歌曲分类，不重新分类，也不将旧扫描诊断显示为待检查项目。
- 点击分类先浏览歌曲；展开「编辑名称与类型」才显示编辑表单。歌曲旁「归属」可增删已有角色、组合或歌手，勾选时不跳动列表。改动先暂存，可「撤销本次修改」。
- 原始歌手标签、专辑艺术家与初始分类保留对照；有百科改名依据的分类显示来源。手动改名不会自动联网核验。
- 点击歌曲试听，使用原播放器及同一个音频元素；只读取原目录，音质、封面和歌词按需读取。不复制音乐、不写标签。
- 「保存并应用到曲库」同时持久保存并立即更新播放器曲库，返回主曲库。主曲库可按独立角色、组合、歌手浏览，多人歌曲在每个归属下分别可见。
- 刷新页面或重启服务后仍自动使用已应用的分类，不需要再次进入创建流程。保存失败保留旧配置和曲库，未保存的编辑不会改变实际播放曲库。
- 分类目录只显示「分类排序」（名称升序、名称降序、歌曲最多）；进入分类或查看全部歌曲时才显示「歌曲排序」。两者独立保存，不会互相覆盖。
- 「文件夹」逐层显示下一层目录和本层歌曲，可返回上一级，不再平铺完整路径。文件夹歌曲数包含子目录；搜索限制在当前目录及其子目录，播放队列仅包含当前层歌曲。空的非音乐目录不显示。
- 「配置与备份」内可导出已保存的完整 JSON（不包含未保存修改），或恢复留底分类后再保存。选择其他扫描目录会切回普通曲库，但保留分类调整。

配置文件：

- `artist-classification/semantic/library-preview.json`：本次初始结果的独立快照，含原目录、全部歌曲归属、实体名称和百科改名依据。旧诊断仅归档，不作为当前待办；网页操作不覆盖它。
- `web-preview/.classification-draft.json`：用户保存的差异及启用状态，绑定初始快照 SHA-256，已加入 Git 忽略；保存失败不替换旧配置。旧版本已保存配置会自动恢复应用。
- `THE_IDOLMASTER-classification.json`：浏览器导出的完整配置。当前没有 APK 内导入逻辑；Android 构建直接读取留底快照和服务端已保存的调整，不因网页保存而改写语义分类源文件。

初始快照由 `python web-preview\classification.py` 从现有分类结果生成；仅在目标文件不存在时创建，防止误覆盖留底。

### 原有播放器功能

- 真实音频播放／暂停、前后切歌、进度拖动。暂停时切歌也立即开始播放。
- 列表循环／随机／单曲循环使用图标，切换时显示短暂的底部 Toast。
- 曲库按歌曲／专辑／歌手／文件夹浏览，支持搜索、名称／专辑音轨／时长／最近添加／年份排序；收藏与歌单入口移至「我的」，不再混在曲库分类中。
- 每行歌曲菜单支持下一首播放、添加到歌单、真实文件信息和隐藏；隐藏歌曲可在设置中单曲或全部恢复。
- 队列支持定位当前歌曲、移除与清空；队列、收藏、所选曲目、进度与布局保存在浏览器本地。
- 底部播放栏的真实封面、曲名、歌手，随当前曲目更新。
- 导航为「曲库／播放／我的」；「我的」用整行横向栏目展示收藏、歌单和本地歌曲，右侧显示数量与进入箭头，下方保留真实最近播放与软件设置。收藏和歌单详情归属「我的」，逐级返回不会跳到曲库；原有收藏与歌单数据保持不变。
- 软件设置支持跟随系统／浅色／深色主题、两种布局、默认启动页与记住播放进度。修改立即生效并保存在当前浏览器。
- 昵称在原位置编辑，输入有效文字即保存，留空时保留上次有效昵称。个人页不需要账号或联网。
- 点击头像上传 JPG／PNG／WebP／AVIF，拖动选择位置、调整正方形裁切大小；保存为最长 384px 的 JPEG，圆形显示。取消不改变原头像。
- 「我的 → 我的歌单」右上角支持创建；播放页的添加按钮选择已有歌单或新建歌单。支持重命名、移除歌曲与按歌单播放，歌曲不重复添加。「我的收藏」支持搜索、排序与按收藏结果播放。
- 紧凑歌曲列表展示歌手、真实音质与时长；曲库优先布局的播放页展示后续队列。
- 原页面上自下向上的声音／硬件输出面板、两个 Tab、遮罩／关闭按钮／Escape 关闭。
- 声音面板只从播放页的硬件输出行打开；导航不再保留「声音」入口。
- 两种布局共用同一个音频元素，切换布局不会同时播放两个音源。
- 点击播放页封面进入歌词；读取同名 LRC（UTF-8、UTF-16、GB18030）或内嵌歌词，支持多时间戳、同时间翻译合并、点击定位和 ±10 秒偏移保存。
- 设置支持 0.5～2 倍速、变速保持音调、列表封面与文件名标题。
- 睡眠定时支持 1～180 分钟与播完本曲再停止；整曲定时在手动暂停或切歌时取消。定时只在当前页面会话生效，刷新后需重新设置。
- 「我的 → 听歌统计」记录真实播放时长与常听歌曲；每轮听满 30 秒或曲长一半（取较短值）计一次，拖动进度不计入时长。
- 空格播放／暂停（输入框、按钮和弹窗内不抢按键）；Media Session 接入系统媒体信息及播放／切歌／跳转，实际按钮可用性由浏览器和系统决定。

声音处理面板接入实际 Web Audio：10 段均衡器（±12dB，平直／人声／低音／明亮／自定义）及标签 ReplayGain（单曲／专辑，专辑标签缺失时回退单曲）。正增益 EQ 自动预留余量；ReplayGain 根据峰值标签限制增益，无峰值标签时不放大。未启用过音效时使用原生播放路径；启用后关闭会将处理节点恢复为中性参数，仍经过 AudioContext。音量由系统控制。

浏览器不能提供可靠的 M3X 硬件输出信息，界面显示「未获取」；这里没有原生 DSD、bit-perfect 或无缝播放的验证结果。功能与原生开发边界见根目录 `M3X-Feature-Completion.md`。

## 扫描与固定目录

「我的 → 软件设置 → 添加扫描目录」打开目录选择。可以浏览子目录／返回上一级，也可粘贴完整路径再点「打开」，最后点「使用此目录」。当前目录显示在添加按钮下方；网页预览保留单目录模式，Android 支持多个目录。选择目录、保存筛选不会自动扫描，点击「开始扫描」后才更新曲库。曲库右上角和设置中的扫描按钮都只扫描当前配置的来源，目录设定随本地服务保存。

首次默认目录为 `web-preview/media`，保留原来的 10 首样例。选择其他目录后，原曲库保持不变，直到手动扫描成功才切换为该目录的扫描结果；歌曲不复制、不修改。扫描后台执行，最多 4 首并行读取元数据，显示进度、速度和完成数量；重复扫描复用未变化文件的元数据，损坏文件跳过，失效文件从当前曲库移除。其他目录中的收藏与歌单引用会保留，切回原目录并扫描后可恢复显示。

扫描需要本机 ffprobe、ffmpeg，读取 FLAC／MP3／WAV／M4A／AAC／OGG／Opus／AIFF／WMA 的真实标签、位深、采样率和封面；能否播放取决于当前浏览器的解码支持。初始 10 首经 ffprobe 核对，全部确为 24bit／96kHz；扫描其他文件时不会写死为 24/96，也不会为有损文件编造位深。

「扫描筛选」可屏蔽 60 秒以下音频，以及填写相对于固定扫描目录的排除子目录（每行一个，含其下级目录）。扫描中可停止，停止后保留上次完整曲库；目录、筛选与缓存随服务保存。没有内嵌封面时，回退同目录 cover.jpg／folder.jpg／front.jpg／cover.png／folder.png。

目录与扫描缓存保存在 `.library.json`，扫描封面在 `scanned-covers/`；头像、昵称、歌单保存在当前浏览器。服务仅监听本机，未发布到网络。

## 检查

- `python -m unittest discover -s D:\CodeFile\M3X-Player\web-preview -p test_server.py`
- `test_preview.cjs` 使用 Playwright，连接上述本地服务检查真实播放、进度、10 首解码和主要交互。
- `test_profile.cjs` 使用 Playwright，检查个人页、设置保存、主题、启动页、进度记忆、页面切换时播放连续和小屏布局。
- `test_features.cjs` 检查暂停时切歌自动播放、模式图标与 Toast、歌单、头像裁切压缩、原位改名、目录选择和真实扫描。
- `python -m unittest discover -s D:\CodeFile\M3X-Player\web-preview -p "test_*.py"` 检查字节范围与扫描（混合音质、固定目录、损坏文件、缓存与重启保存）。
- `node web-preview/test_player_tools.cjs` 检查 LRC 解析、偏移、翻译合并与 ReplayGain 计算。
- `test_completion.cjs` 检查分类排序、歌曲菜单、隐藏恢复、队列编辑、倍速、歌词定位、实际 Web Audio 节点、睡眠定时和听歌统计。歌词／增益使用浏览器隔离夹具，统计使用真实四秒 WAV 流，均不写入用户曲库。
